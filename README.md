# TiendaCatalogo

Aplicación de consola en C# (.NET 8) para gestionar los productos de una tienda en memoria.

Práctico del Bloque 1 — POO, interfaces, `List<T>` y LINQ.

## Qué hace

- Lista todos los productos
- Busca un producto por Id
- Filtra productos por categoría
- Agrega un producto nuevo

## Estructura

```
TiendaCatalogo
├── Models
│   └── Producto.cs
├── Repositories
│   ├── IProductoRepository.cs
│   └── ProductoRepository.cs
└── Program.cs
```

## Cómo ejecutarlo

```bash
git clone https://github.com/santynadamas/tiendaCatalogo.git
cd tiendaCatalogo
dotnet run
```
